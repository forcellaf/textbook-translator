## Output rules

- Output ONLY LaTeX body content. No preamble, no \documentclass, no \usepackage, no
  \begin{document} or \end{document} — those already exist. No commentary, no code
  fences around the response, no "Here is the translation".
- Translate ALL prose: headings, body text, figure captions, table cells, exercise
  text, footnotes. The only things that keep their original form are mathematics and
  image tokens.
- Never leave a \begin{...} unclosed, and never split an environment across the end of
  your output.

## Structure

- Chapter headings   -> \chapter{...}
- Numbered sections (12.1 ...)    -> \section{...}
- Numbered subsections (1. ...)   -> \subsection{...}
- Worked examples (例12.3)        -> \begin{example} ... \end{example}
- Exercises / problems (习题 N.N) -> \begin{exercise} ... \end{exercise}
- Chapter summaries (提要)        -> \section*{Summary}

## NUMBERING -- READ THIS CAREFULLY

LaTeX generates the numbers for chapters, sections, subsections, figures, tables,
examples and exercises automatically. The preamble is already configured so that this
volume starts at chapter 12, so section 1 of chapter 12 comes out as "12.1" on its own.

**Strip the number from the source text in every one of these cases.** Writing it
yourself produces a doubled number such as "12.1 12.1 Electric Charge" or
"Figure 12.3. Figure 12.3 Charge distribution".

| source | WRONG | CORRECT |
|---|---|---|
| `12.1 电荷` | `\section{12.1 Electric Charge}` | `\section{Electric Charge}` |
| `1. 电荷的种类` | `\subsection{1. Types of Charge}` | `\subsection{Types of Charge}` |
| `例12.3` | `\begin{example} Example 12.3 ...` | `\begin{example} ...` |
| `习题 12.1` | `\begin{exercise} 12.1 ...` | `\begin{exercise} ...` |
| `图 12.3 电场分布` | `\caption{Figure 12.3 Field distribution}` | `\caption{Field distribution}` |
| `表 12.1 相对电容率` | `\caption{Table 12.1 Relative permittivity}` | `\caption{Relative permittivity}` |

THE ONE EXCEPTION IS EQUATIONS. If the source carries a `\tag{12.1}`, keep it exactly
as given. `\tag` deliberately overrides LaTeX's automatic equation number so the book's
own numbering is preserved -- the prose refers to those numbers, so they must not change.
Equations without a `\tag` in the source get no tag from you either.

Numbers that appear in PROSE are different: they are ordinary text and must be
translated, not stripped. "如图12.3所示" becomes "as shown in Figure 12.3", and
"由式(12.1)" becomes "from Eq. (12.1)".

Use ONLY these environments: example, exercise, figure, table, tabular, itemize,
enumerate, equation, align, center, minipage. They are the only ones defined. Do not
invent environments such as `solution`, `problem`, `theorem`, or `note` — an undefined
environment stops the build. If the source has a solution following an example, put it
inside the same example environment as a new paragraph beginning \textbf{Solution.}

## Mathematics

- Preserve ALL mathematics character for character. Do not simplify, correct,
  re-derive, or reformat any formula, even if it looks wrong.
- Inline math stays inline: $...$. Display math becomes \begin{equation}...\end{equation}
  when the source numbers it, or \[...\] when it does not.
- Keep any \tag{12.1} exactly as given — that is the book's own equation number.
- Every symbol that was inside math must stay inside math. Never let a formula become
  body text.
- Escape & % # _ and a literal $ when they are prose rather than markup.

## Figures — this is the part most likely to go wrong

Images appear in the source as: ![](IMG_0042)

Convert each one to:      \bookfig{IMG_0042}{translated caption}

- Reproduce the IMG_nnnn token EXACTLY. Never renumber, alter, abbreviate or omit one.
  Do not add a file extension or a path. Every token in the input must appear exactly
  once in your output.
- The caption is usually the line just after the image, beginning 图 12.3. Translate it
  and put it in the second argument WITHOUT the "图 12.3" label — LaTeX adds
  "Figure 12.3." itself. So `图 12.3 电场分布` becomes
  `\bookfig{IMG_0042}{Field distribution}`.
- If an image has no caption in the source, use an empty second argument: \bookfig{IMG_0042}{}
- Where two images form one figure with (a) and (b) parts, use:
      \bookfigtwo{IMG_0001}{(a)}{IMG_0002}{(b)}{shared caption}

## Tables

Convert HTML tables to LaTeX tabular inside a table float, using booktabs rules
(\toprule, \midrule, \bottomrule). Give the tabular a column spec matching the widest
row. If a table's rows have differing cell counts, reproduce the content as faithfully
as you can and keep the column count consistent — do not invent data to fill gaps.

## Finally

Do not summarise, shorten, merge or omit anything. Translate every line. If a short
span is already in English (an equation label, a proper noun, a citation), leave it.
